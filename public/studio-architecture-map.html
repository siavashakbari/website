Architectural Standards & Naming Logic
The core algorithmic rules governing URL paths, sticky asset codes, file names, and layout sizing.

#1 Sticky Unique Code

Every asset receives an immutable 4-digit numeric code upon creation (e.g. 1211). This code never shifts or re-indexes when items are added or removed.

Format: [1001-9999] (e.g. 1211, 1221, 1317)

#2 Route-Based Dynamic Code

Generated dynamically from placement hierarchy: ${uniqueCode}-${DISCIPLINE}-${CATEGORY}-${PROJECT}. Synchronized between Vault and website.

e.g. 1211-GRAPHIC-DESIGN-VISUAL-IDENTITY-SHEKARCHIAN-SWEETS

#3 Database Image Filename

The image title and database filename standard always mirrors the dynamic code plus original uppercase extension (.JPG / .PNG / .MP4).

e.g. 1211-GRAPHIC-DESIGN-VISUAL-IDENTITY-SHEKARCHIAN-SWEETS.JPG

#4 Dedicated Canonical Route

The dedicated photo showcase route is always /${discipline}/${specialty}/${project}/${dynamicCode}. Short code /1211 automatically redirects here.

/graphic-design/visual-identity/shekarchian-sweets/1211-...

#5 Layout Sizing Modes

UI01: Vertical scroll (editorial).
UI02: Horizontal filmstrip with wheel translation.
UI03: Equal cards grid.
UI04: Interactive video player.

Responsive: 100dvh desktop / touch gesture mobile

#6 Resilient Fallback Routing

Zero-404 guarantee: If a user enters an older shifted code, legacy code (SA-VI-SHEK-01), or 4-digit short code, the router auto-resolves and redirects safely.
