## Edit notes

- `category` must be one of: Education | Job | Freelance | Project
- `role` = position (shown above the description, separate)
- `period` = dates only
- `lengthYears` = number — used only when period does **not** include Present
  - Present / ongoing → small circle only (no capsule)
  - Finite duration jobs → elongated capsule that fills gradually as the line passes through
  - `0` = point event / circle only
- Leave role / period blank if none
- Keep EN + FA pairs when changing text
- You can reorder, add, or delete timeline items
- Numbering is only for reference
